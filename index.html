📥 Cómo instalar más voces e idiomas
1Abre Configuración → Hora e idioma → Voz
2En "Voces", pulsa "Agregar voces"
3Busca el idioma deseado (ej. Español México, Español España) y descárgalo
4Recarga esta página — las nuevas voces aparecerán automáticamente en el selector
💡 Windows 11 incluye voces neurales de alta calidad (Paloma, Jorge, Elena). En Windows 10 están disponibles como descarga opcional.
1Abre Preferencias del sistema → Accesibilidad → Contenido hablado
2Haz clic en el menú "Voz del sistema" → "Personalizar..."
3Filtra por idioma y descarga las voces que quieras (ej. Mónica, Juan, Paulina)
4Recarga la página para que aparezcan en el selector
💡 macOS ofrece voces Premium de alta calidad (~1 GB cada una) y voces compactas gratuitas.
1Abre Ajustes → Accesibilidad → Texto a voz (o busca "TTS" en ajustes)
2Selecciona Google Text-to-Speech como motor preferido
3Toca el ícono ⚙️ → Instalar datos de voz → elige el idioma
4Usa Chrome en Android para acceder a las voces instaladas
💡 Samsung también ofrece su propio motor TTS con voces en español disponibles en Galaxy Store.
1Abre Ajustes → Accesibilidad → Contenido hablado → Voces
2Elige el idioma (ej. Español) y selecciona la voz que quieras descargar
3Toca ⬇ Descargar — las voces mejoradas son de mayor calidad pero pesan más
4Usa Safari en iOS/iPadOS para la mejor compatibilidad con Web Speech API
💡 iOS 17+ incluye voces neurales (Mónica, Jorge) de excelente calidad offline.
1Instala espeak-ng o festival via terminal: sudo apt install espeak-ng
2Para voces de mayor calidad, instala speech-dispatcher + pico2wave
3En Chrome/Chromium, las voces eSpeak estarán disponibles automáticamente
4Para voces neurales: considera usar Coqui TTS o conectar a una API externa
💡 La compatibilidad con Web Speech API varía por distribución. Chrome tiene mejor soporte que Firefox en Linux.
